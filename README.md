# 🎮 미니게임 모음

태블릿에서 터치로 즐기는 미니게임 모음입니다.
설치나 빌드 없이 브라우저만 있으면 실행되고, 홈 화면에 추가하면 앱처럼 전체 화면으로 쓸 수 있어요.
한 번 열어 두면 인터넷이 없어도 플레이할 수 있습니다.

## 게임 목록

| 게임 | 방법 | 기록 |
| --- | --- | --- |
| 🎈 풍선 터뜨리기 | 30초 동안 올라오는 풍선 터치 (⭐ 황금 풍선 3점) | 높은 점수 |

| ⚡ 반응속도 테스트 | 초록색이 되면 바로 터치, 5번 평균 | 빠른 시간 |

최고 기록은 기기(브라우저)에 저장됩니다.

## 태블릿에서 실행하기

### 방법 1. GitHub Pages로 올리기 (추천)

1. 이 저장소를 `main` 브랜치에 병합합니다.
2. GitHub 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
3. 잠시 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다.
4. 태블릿에서 그 주소를 열고 홈 화면에 추가합니다.
   - **iPad (Safari)**: 공유 버튼 → **홈 화면에 추가**
   - **안드로이드 (Chrome)**: 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**

### 방법 2. 컴퓨터에서 바로 띄우기

같은 와이파이에 연결된 컴퓨터에서:

```bash
python3 -m http.server 8000
```

태블릿 브라우저에서 `http://<컴퓨터 IP>:8000` 으로 접속합니다.

> `index.html` 파일을 직접 열어도 실행되지만, 오프라인 저장과 홈 화면 앱 기능은 `http(s)` 주소로 열어야 동작합니다.

## 새 게임 추가하기

1. `js/games/` 에 새 파일을 만들고 `registerGame({...})` 으로 등록합니다. 기존 게임 파일을 참고하세요.
2. `index.html` 아래쪽에 `<script src="js/games/새파일.js"></script>` 를 추가합니다.
3. `sw.js` 의 `ASSETS` 목록에 새 파일을 넣고 `CACHE` 버전을 올립니다.

`start(api)` 에서 쓸 수 있는 주요 기능 (`js/app.js` 의 `makeApi` 참고):

- `api.stage` – 게임을 그릴 영역
- `api.info(text)` – 위쪽 점수/시간 표시
- `api.timeout / interval / loop` – 게임이 끝나면 자동으로 멈추는 타이머
- `api.countdown(cb)` – 3, 2, 1, 시작!
- `api.sound('tap' | 'pop' | 'good' | 'bad' | 'win')`, `api.vibrate(ms)`
- `api.floatText(text, x, y, color)`, `api.shake(element)`
- `api.end({ score, title, text })` – 게임 끝, 결과 창 표시 및 최고 기록 저장
